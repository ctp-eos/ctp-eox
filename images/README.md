# Images Folder

This folder contains all image assets used in the project.

## Contents

- **/raw** — Original, unedited high-resolution images.
- **/processed** — Optimized images ready for web or app use.
- **/thumbnails** — Small preview versions for faster loading in galleries.

## Usage Guidelines

- Use images from `/processed` for best performance.
- Refer to `/raw` if you need the original quality for editing or print.
- Use thumbnails to improve load times in listings or galleries.

## Naming Conventions

- Filenames use lowercase letters, numbers, and hyphens.
- Names describe the image content clearly (e.g., `logo-primary.png`).

## Contribution

- Optimize new images before adding.
- Include source files in `/raw` for new or modified images.
- Follow existing naming conventions.
